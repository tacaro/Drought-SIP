# README

Analysis scripts as reported in Caro et al. (in review). Preprint available:

## Directory

Folders
- `cache/` cached data between analysis scripts
- `data/` primary data folders accessed by analysis scripts
- `data_output/` data summaries output by analysis scripts
- `fig_output/` output figures from analayis scripts
- `source/` assorted functions called in analysis scripts

Scripts
- `01_` LiCOR CRDS data analysis
- `02_` GC data analysis
- `03_` tracer calculations
- `04_` GC/P/IRMS data processing and analysis
- `05_` LCMS metabolomics data sub-analysis
- `06_` combined GC and LC metabolomics data analysis
- `07_` lipid quantification via GCMS
- `08_` codon usage bias maximum potential growth rate estimation via gRodon2
- `09_` DNA-SIP data analysis
- `10_` toy growth modeling experiments
- `11_` toy growth modeling experiments visualization
- `12_` Volumetric water content (VWC) data processing from TMS sensors
- `13_` abiotic CO2 experiment processing and visualization
- `14_` gRodon2 data visualization
- `15_` 
- `16_` testing inchikey mapping on metabolomics data
- `17_` nucleotide skew analysis

Other files are miscellaneous and are included for personal reference.
